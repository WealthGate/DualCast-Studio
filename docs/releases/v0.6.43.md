# OpenChurch Broadcast Studio v0.6.43

Control the studio from Android phones and tablets, iPhone, and iPad with the new OpenChurch Remote mobile web app.

- **Camera and scene switching:** cue Preview or send a configured scene live, TAKE with Cut/Fade/Crossfade, freeze/unfreeze, and black/restore Program.
- **Text, lyrics, and Scripture:** stage announcements or lyrics privately, load references through the desktop's selected Bible provider or offline library, review saved cues, show staged text, and navigate within a presentation.
- **Scrolling announcements:** update an existing Program ticker's message, speed, direction, visibility, and pause state while retaining its styling and other pending Preview edits.
- **Essential service controls:** recording start/stop, master Program audio volume, text/lower-third visibility, theme/logo only, and a silent Program confidence picture with stream and recording status.
- **Phone and tablet interface:** large touch buttons, portrait/landscape layouts, home-screen installation over HTTPS, optional screen wake lock, and address sharing without exposing the PIN.
- **Private access:** same-Wi-Fi browser control, plus a configurable private HTTPS address for access through mobile data or another network using Tailscale Serve or a trusted proxy. Tailscale setup is separate; no router port forward is needed for the documented private setup.
- **Session protection:** random eight-digit PIN defaults, signed-in browser sessions, PIN attempt limits, explicit command acknowledgements, duplicate-command protection, and controls that lock when the studio disconnects. Commands are never queued for later replay.

**Get started:** after updating, open **Venue & Outputs → Mobile Control & LAN Output**, start the hub, open a non-loopback operator address on your mobile device, and enter the PIN shown in Venue. Earlier four-digit PINs are replaced with a random eight-digit PIN; use the current PIN shown on the desktop.

For an app icon, use the private HTTPS address and choose **Share → Add to Home Screen** in Safari on iPhone/iPad or **Install app** in Chrome on Android. This is an installable web app; there is no separate app-store download.

[Mobile setup, internet access, and installation guide](https://github.com/WealthGate/DualCast-Studio/blob/v0.6.43/docs/mobile-control.md)

**Install the desktop update:** choose **Check for Updates** in OpenChurch Broadcast Studio, or download the Windows, macOS, or Linux installer below. The studio computer must remain running to use the remote. Physical iOS/Android installation and external-network operation should be checked on your devices after private-network setup.
