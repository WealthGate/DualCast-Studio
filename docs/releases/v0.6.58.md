# v0.6.58 — More room for service controls

Explanatory captions have been removed from the desktop panels, Multiview and mobile remote. The freed space is available for slides, audio controls and service content. Live indicators, input labels, error messages and confirmation prompts remain visible where they are needed.

This update also includes the mobile Scripture and Service controls, dock layout lock and streaming fixes introduced in v0.6.57. Double-tap a verse on the mobile Scripture tab to send it to Preview and Program. Open **Panels → Lock dock layout** to protect the current workspace arrangement.

Choose **Menu → Check for Updates** in the studio and restart to install. Reopen the existing mobile remote address after the desktop update.
