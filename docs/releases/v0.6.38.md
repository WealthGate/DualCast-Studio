Find installed VST2 plugins from Audio Mixer and enable ReaStream with clear setup and recovery instructions.

- Add **Scan installed VST2 plugins** for common Windows x64 VST folders, Windows VST registry locations, `VST_PATH` and remembered custom folders. Use **Scan folder…** for another location, or **Add VST2 .dll** for a single installed file.
- Validate each DLL in an isolated helper, skip duplicate registrations and show incompatible or failed files under **Scan details**. Existing plugin IDs and saved presets are preserved. Scans do not enable plugins or move their installed files.
- Refresh plugin selection from action results as well as status events. **Enable plugin** opens native controls automatically. Distinguish a missing audio host from an unsupported platform, flag moved/missing DLLs, retain activation errors and wait for scan helpers to release files before activation.
- For ReaStream, use the **64-bit ReaPlugs VST2** DLL. After enabling it, turn on **Enable audio/MIDI**, select **Receive audio/MIDI**, and match the sending instance's identifier. Receiver audio continues without a microphone and follows EQ, master volume and **Mute all**.
- Update the bundled PDF and online user guide, and add release checks for the real plugin UI and native audio bridge.

Verified locally with 258 unit tests, a production build, installed stereo/four-channel ReaStream scanning and activation, real native PCM return, invalid-DLL recovery, repeat scans, saved custom folders, and the AudioWorklet/preload/native audio bridge including crash fallback, master/mute and a stable Program audio track. A live ReaStream network sender was not included in these checks.

**Compatibility:** one Windows x64 VST2 effect at a time. VST3, 32-bit plugins and native hosting on macOS/Linux remain unsupported. Plugins must be enabled again after restarting the app.

Existing users: choose **Check for Updates**, download **v0.6.38**, then **Restart & Install**.
