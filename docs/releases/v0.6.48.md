# v0.6.48 — Plugin audio, floating panels and slide search

In **Audio Mixer → VST audio plugin**, choose **Replace Source Audio** and enable ReaStream or another receiver to make the plugin the only Program audio source. In ReaStream, choose **Receive audio/MIDI** and match the sender's identifier. Program stays silent when the receiver has no signal or the plugin is stopped. To return to the local mix, bypass the plugin and choose **Process Source Audio**. The update also fixes plugin bypass and invalid-action messages caused by audio bridge startup in the installed app.

Windows x64 supports VST2 and VST3 audio effects. Use **Scan installed VST plugins**, **Scan folder…** for custom locations and VST3 bundles, or **Add plugin file** for a standalone file. Program hosts one stereo effect or receiver at a time. See the [VST and ReaStream guide](../vst-scanning-and-reastream.md).

Use the arrow on a dock header to float a panel inside the workspace. Drag the header to move it and the bottom corner to resize it. Use the return arrow to put it back in its dock.

In **Service Schedule**, search by item title, Scripture reference or slide text. Choose **Browse Slides** on an item to find a slide without changing Program. Select a specific slide to show it live. In **Lower Third Studio**, use **Slide deck** to follow the Preview deck or choose another deck. **Find slides** searches the entire queue.

Choose **Menu → Check for Updates**, download the update, and select **Restart & Install**. Installers are available on the [v0.6.48 release page](https://github.com/WealthGate/DualCast-Studio/releases/tag/v0.6.48).
