# Display workflow, animations and uploaded files · v0.6.41

Open **Controls → Display screens** or **Tools → Display Screens & Mode…**. Connected screens appear at the top in every display mode. The previous fixed-height flex layout let the Independent Layout controls shrink that list to zero height. The panel now scrolls its contents without collapsing screen choices, and Backgrounds and Sanctuary Displays read one shared inventory. Screen detection starts independently of capture-source discovery and layout settings; stale refresh responses cannot replace a newer inventory.

Select receiving screens and choose **Show selected screens**. **Mirror Program · all screens** sends the Program picture, including its Designer graphics and animations. It overrides earlier individual screen routes while keeping uploaded files and saved background selections. **Independent Layout · all screens** restores independent sanctuary text and saved screen backgrounds. **Individual screen layouts** is shown when screens have different assignments. Applying a screen background explicitly selects independent output for that screen. Applying a shared sanctuary background selects the independent default; other explicit screen routes remain available. Choosing Mirror Program again returns all sanctuary screens to Program. Dedicated lower-third output remains a separate output.

Older installations retain their current background assignments until an explicit mode choice is made. Removing an individual background also removes its individual route, so it follows the current shared mode. This separates saved media from routing decisions and removes the old silent background-overrides-mode rule. A shared resolver now controls the renderer and main-process video/frame routing. Mirrored video capture runs when selected screens actually require it.

Independent screens follow the selected lower-third entrance, exit and duration when showing a new live cue, changing slides or hiding text. Outgoing text remains for its exit. Live edits within the same cue update text without replaying the entrance; rapid changes cancel stale animations. None remains an immediate change. Freeze pauses active text animations and background video, while Cut to Black hides output immediately. Independent layouts retain their sanctuary typography; mirrored outputs retain Program's full design.

**Lower Third Studio → Designer · Title + Content** now offers twelve styles. Beacon and Cobalt use split title blocks; Ember and Verdant add accent rails; Porcelain and Royale add double frames. Existing Prism, Aurora, Editorial, Glassline, Momentum and Sanctuary remain available. New preset text uses extra-bold or black weight. Each of **Title styling** and **Content styling** independently controls text/panel colors, opacity, font, weight, size, alignment, letter spacing, bold, italic and underline. Choose a common font or type an installed font name. Title styling also applies to automatic song titles and Scripture references. Existing saved emphasis and Classic formatting are retained. Shape, composition, logo and animation controls remain editable.

In **Backgrounds → Your uploaded files**, each file has **Delete**. A confirmation names the file and explains that only OpenChurch's stored copy is removed. Original files and other uploads are retained. Current background references and local saved profiles switch to the affected output's base color; independent routes and styling remain. Missing uploads can also be removed. Cancel leaves files and assignments intact. Failed library/filesystem changes restore the library entry and assignments. Deleted files remain deleted after reopening the app, and originals can be uploaded again. Exported profiles or copies on other computers can still reference a deleted local asset; that asset must be uploaded there again.

Verification combines the full unit suite with real Electron checks for visible/hittable screen choices, mode changes, hotplug, independent Show live/slide-change/exit animations, no replay on same-cue edits, Mirror Program pixels despite saved backgrounds, screen-specific routing, image/video playback, Freeze/Black, deletion/cancel/missing files, original preservation, saved-profile cleanup, persistence and shutdown. Designer checks render all twelve styles, test animation endpoints, editable text weights/fonts/colors, transparent lower-third output, Scripture navigation and narrow docks. New preset contrast is checked at both gradient endpoints. Release CI additionally checks streaming/recovery and Windows native hosts before packaging all platforms. These checks provide regression coverage; they do not establish that every hardware or external-service configuration is free of bugs.
